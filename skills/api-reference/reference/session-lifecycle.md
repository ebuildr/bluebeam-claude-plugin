# Studio Session lifecycle (from the Bluebeam Studio Session Guide)

1. Create: `POST /publicapi/v1/sessions` body `{ Name, Notification, Restricted, SessionEndDate (UTC ISO), DefaultPermissions: [{Type, Allow}] }`. Types: SaveCopy, PrintCopy, Markup, AddDocuments, FullControl, MarkupAlert. Allow values: Allow, Deny, Default. The API default is Deny, so set permissions explicitly. Response `{ Id: "123-456-789" }`. End date triggers reminder emails at 7 days, 2 days and 24 hours.
2. Add PDFs (no PDF/A): `POST /sessions/{sessionId}/files` `{ Name (ends .pdf), Source, Size?, CRC? }` -> `{ Id, UploadUrl, UploadContentType }`; `PUT` bytes to UploadUrl with `x-amz-server-side-encryption: AES256` and `Content-Type: application/pdf` within 10 minutes; `POST /sessions/{sessionId}/files/{id}/confirm-upload` -> 204.
3. Add people: `POST /sessions/{sessionId}/invite` `{ Email, Message }` (email invitation, works for people without Studio accounts) or `POST /sessions/{sessionId}/users` `{ Email, SendEmail, Message }` (adds a known Studio account directly). The creator is the Host with full control.
4. Finalize: `PUT /sessions/{id}` `{ "Status": "Finalizing" }` removes everyone but the Host. For each file: `POST /sessions/{sessionId}/files/{id}/snapshot`, then poll `GET .../snapshot` until `Status` is `Complete` (`DownloadUrl`) or `Error`. Statuses: NoSnapshot, Requested, InProgress, Complete, Error. Download the snapshot (PDF with markups merged). Finally `DELETE /sessions/{id}`.
   If the file came from a Project (`checkout-to-session`), `POST /sessions/{sessionId}/files/{id}/checkin` `{ Comment }` writes the marked-up copy back to the Project instead.
